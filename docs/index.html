How it works

1

Recall

Queries Hindsight for the account's highest-CTR posts. Every recommendation cites what it learned from.

2

Draft + approve

Groq drafts hook, caption and timing. Nothing is scheduled until a human approves.

3

A/B test

Memory-informed variant vs control; the winner is measured by CTR.

4

Remember

The winning hook is written back to Hindsight - learning that compounds across runs.
