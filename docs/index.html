How it works

1

Recall

Queries Hindsight for the account's historically highest-CTR posts. Every recommendation cites the posts it learned from.

2

Draft + approve

Groq drafts hook, caption, hashtags and best posting time. Nothing is scheduled until a human checks the approval box.

3

A/B test

Variant A (memory-informed) vs variant B (control) are scheduled; the simulator measures CTR and picks a winner.

4

Write back

The winning hook is retained in Hindsight as a top_hook memory - durable learning that survives redeploys and compounds over time.

Why the memory layer matters

Most LLM social tools start from zero every session. This agent treats memory as first-class: Hindsight (Vectorize) stores every post's metrics as facts (50 posts + 50 comments seeded), recall is semantic - "highest CTR posts about integrations" - and the A/B winner is written back as a first-class memory. Open the app and the Memory panel shows exactly what the agent knows, including the winning hooks and their CTRs. That transparency is the point: recommendations are grounded, auditable, and improve with every test.

Deploy your own

One click deploys the full app (API + UI) to your Render account; you paste in your own keys.

You will be asked for three env vars at deploy time (get free keys at console.groq.com and vectorize.io for Hindsight):

VariableValue
HINDSIGHT_BASE_URLhttps://api.hindsight.vectorize.io
HINDSIGHT_API_KEYyour Hindsight API key
GROQ_API_KEYyour Groq API key

Prefer self-hosting? The repo runs anywhere Node 20+ runs: npm run install:all && npm run build && npm start.
