# Demo narration script — Social Engagement Agent

Read at a relaxed pace. Total ~3 min 30 s with screen pauses.
(Used for the TTS voiceover in demo/demo-full-1080p.mp4; re-record with your own voice any time.)

## Section 1 — Intro (~30 s)

Hi, I'm Sujal — and this is the Social Engagement Agent. It's an AI copilot
for social media with one big idea: it actually remembers. Every post, every
comment, and every A/B test result is stored as memory in Hindsight, a vector
memory layer. So instead of guessing what to post, the agent recalls what
already worked for your account — and gets smarter with every test. Let me
show you.

## Section 2 — The problem: no memory (~40 s)

First, what happens without memory. Here's a fresh agent — the memory panel
is empty, nothing retained yet. I ask it for a hook about data sync, and it
gives me something generic. Any AI can write a generic hook. It doesn't know
that my audience clicks on before-and-after numbers, that post eleven hit
seven percent click-through with exactly that pattern. Without memory, every
session starts from zero.

## Section 3 — The demo: retain, recall, test, write back (~2 min)

So let's give it memory. One import call retains fifty posts and fifty
comments into Hindsight — watch the panel: one hundred memories. Now the same
question. The recommendation is different this time: provenance on every
suggestion — it cites post eleven, seven percent CTR, because that's what it
recalled. The LLM drafts the hook, but the memory decides the strategy.

Here's the part I care about: nothing is scheduled until I check this
approval box. A human stays in the loop.

Now the A/B test: variant A is memory-informed, variant B is the generic
control. I schedule both, and the results come in — A wins by roughly three
times the click-through. And here's the payoff: the winning hook is written
back into Hindsight as a new memory. Watch the winning-hooks counter tick up.
The next recommendation will cite today's test. That's the learning loop.

Bonus: it answers comments too. Memory-informed reply, tagged by issue,
similar comments recalled from history.

## Section 4 — Wrap-up (~30 s)

The surprise for me was how much provenance changes trust. Because every
recommendation cites the exact posts it learned from, I stopped thinking of
it as an AI guessing, and started treating it as a teammate with
account experience. Memory is retained in Hindsight, so the agent survives
redeploys — it only gets wiser. Thanks for watching — the links are below.
